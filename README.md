# Chirp Signal Generator

Proyek ini merupakan implementasi pembangkit sinyal **Chirp** (*Linear Frequency Modulated* / LFM) untuk keperluan simulasi pemrosesan sinyal, pengujian sistem radar, sonar, maupun pengukuran respons frekuensi perangkat RF/audio.

## 📋 Deskripsi Singkat

Sinyal *chirp* adalah sinyal sinusoidal yang frekuensinya berubah secara kontinu seiring waktu

## 🛠️ Prasyarat & Lingkungan

Sesuaikan bagian ini dengan *platform* yang digunakan dalam proyek Anda:

* **Python (SciPy / NumPy / Matplotlib):** Python 3.8+
* **GNU Radio:** Versi 3.8 atau 3.10+ (menggunakan blok *VCO* + *Signal Source Sawtooth* atau *Chirp* bawaan)
* **LabVIEW / MATLAB:** Versi standar dengan *Signal Processing Toolkit*
